# 小宇宙播客 → Obsidian 笔记

粘一个小宇宙分享链接，点一下按钮，等两三分钟，一篇结构化的中文笔记就出现在你的 Obsidian 里。

全程在你自己电脑上跑，**没有服务器、没有账号系统、你的笔记不会上传到任何地方**。

```
小宇宙链接  →  抓文字稿  →  AI 提炼  →  Obsidian 笔记
```

---

## 笔记长什么样

每篇自动生成的笔记包含这些部分：

| 部分 | 内容 |
| --- | --- |
| **frontmatter** | 标题、播客名、时长、日期、原链接、标签，方便 Obsidian 检索 |
| **核心结论** | 3～5 条，整集最值得记住的观点 |
| **思维导图** | mermaid 语法，Obsidian 里直接渲染成图 |
| **思维框架** | 主播和嘉宾是**怎么思考问题**的，可以迁移到你自己的工作里 |
| **要点展开** | 按话题分段，每段带时间戳 |
| **金句摘录** | 原话摘录 + 时间戳 |
| **优秀表达沉淀** | 值得学的说法，中文播客收讨论/会议话术，英文播客收日常高频表达 |

另外它还会自动做两件小事：

- 文件名自动编号 `001 / 002 / 003…`，并在你的笔记目录里维护一个 `_Index.md` 索引页，按主题分类 + 按时间登记。
- 提炼「优秀表达」前，先扫一遍你已有的笔记，**已经收过的表达不再重复收**（想让它连带扫描其他目录，见文末「进阶设置」）。

## 你需要准备什么

- 一台 **Mac**（Windows 也能跑，但下面的截图和路径以 Mac 为例）
- 装好的 **Obsidian**，并且知道你的库（vault）在哪个文件夹
- 一个**大模型 API Key**（下面第 3 步教你 5 分钟拿到，几块钱能用很久）

不需要懂编程，不需要会写代码。

---

## 安装：4 步

### 第 1 步：装一个运行环境（只做一次）

打开「终端」应用（按 `⌘ + 空格`，输入 `终端`，回车），把下面这行**整行复制粘贴**进去，按回车：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

跑完看到 `Successfully installed` 之类的字样就好了。**这是你唯一需要用终端的地方**，之后全在网页上点。

> 这一步装的是 `uv`，它会自动帮你准备好 Python 和所有依赖，你不用管细节。

### 第 2 步：下载项目

点这个仓库页面右上角绿色的 **Code** 按钮 → **Download ZIP**，下载后**双击解压**。

把解压出来的文件夹拖到你喜欢的位置，比如「文档」里。建议路径里**不要有中文和空格**。

### 第 3 步：拿一个大模型 API Key

任选一家，注册后在控制台创建 API Key，复制备用（形如 `sk-xxxxxxxx`）：

| 服务商 | 特点 | 接口地址 | 模型名 |
| --- | --- | --- | --- |
| **火山方舟 / 豆包**（推荐） | 新用户有免费额度，中文效果好 | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seed-1-6-250615` |
| **DeepSeek** | 便宜，一篇笔记几分钱 | `https://api.deepseek.com/v1` | `deepseek-chat` |
| **OpenAI** | 需要海外支付方式 | `https://api.openai.com/v1` | `gpt-4o` |
| **Ollama**（本地模型） | 完全免费、完全离线，效果弱一些 | `http://localhost:11434/v1` | `qwen2.5:14b` |

> 火山方舟的模型名也可以填推理接入点 ID（`ep-` 开头那串）。

### 第 4 步：启动

双击文件夹里的 **`启动播客笔记.command`**。

首次启动会自动装依赖，慢一点（1～3 分钟），装完浏览器会自动打开界面。之后每次启动都是秒开。

> **如果双击被系统拦住**（提示「无法打开，因为来自身份不明的开发者」）：右键点它 → 选「打开」→ 再点「打开」。只需处理一次。
>
> 那个黑色终端窗口是服务本体，**用的时候别关**，用完关掉就等于退出程序。

## 使用：全在网页上点

### 首次配置（一次就好）

界面右上角点 **设置**，填三样：

1. **Vault 路径** —— 你的 Obsidian 库文件夹绝对路径
2. **笔记子目录** —— 笔记放在库里的哪个文件夹，比如 `Podcasts`，不存在会自动创建
3. **API Key** —— 第 3 步拿到的那串；接口地址和模型名按上面表格填

点 **保存设置**，再点 **测试连通**。看到「可用」就成了。

> **不知道 vault 路径怎么填？** 在 Obsidian 里右键任意笔记 → 「在系统资源管理器中显示」/「Reveal in Finder」，在弹出的 Finder 窗口里右键那个文件夹 → 按住 `⌥ Option` → 「拷贝……的路径名称」，粘进来即可。

### 登录小宇宙（强烈建议）

界面上点 **小宇宙登录**，填手机号 → 收验证码 → 填进去 → 登录。

登录后就能直接拿**官方文字稿**，又快又准。不登录的话，只能靠本地转录（慢，而且要额外装东西）。

登录状态存在你自己电脑上（`~/.xyz2ob/`），不会进这个项目文件夹，也不会被上传。

### 生成笔记

1. 在小宇宙 App 里点单集的分享 → 复制链接
2. 粘到界面的输入框（也可以点 **读剪贴板** 让它自己取）
3. 点 **生成笔记**

界面会实时显示进度：抓取 → 文字稿 → AI 提炼 → 写入。一小时的播客大约 2～4 分钟。

完成后可以直接点 **在 Obsidian 打开**，或者 **复制 Markdown**。

### 想重新生成某一集

同一集默认只生成一次。勾上 **已记过也重新生成**，会覆盖原来那篇，序号和编号都保留。改了配置、换了更好的模型之后想重跑，用这个。

## 常见问题

**界面打不开 / 双击没反应**
先确认第 1 步的 `uv` 装好了。还不行就打开终端，`cd` 到项目文件夹，双击那个 `.command` 文件看终端里的报错信息。

**提示端口被占用**
说明已经有一个在跑了，直接访问 `http://127.0.0.1:8765`。或者把之前的黑色终端窗口关掉再启动。

**提示 vault 路径不存在**
路径要填**绝对路径**（以 `/` 开头），不是 `~/Documents/...`。用上面「拷贝路径名称」的方法最稳。

**提示鉴权失败 401 / 余额不足**
Key 复制错了或者没充值。检查 Key、接口地址、模型名三者是否配套——三家的地址和模型名不能混着填。

**提示接口地址不对 404 / 模型名不存在**
对照上面表格重新填一次。火山方舟要注意模型是否已在控制台开通。

**提示「这一集还没有官方文稿」**
小宇宙没给这集生成文稿。要么换一集，要么装本地转录兜底（见下）。付费单集拿不到文稿。

**提示登录已过期**
点 **换账号** 重新登录一次。

**笔记生成了但 Obsidian 里看不到**
在 Obsidian 里刷新一下，或确认「笔记子目录」填的是这个库里的目录。iCloud 同步的库偶尔会延迟。

**思维导图显示成一堆代码**
Obsidian 1.4 以上原生支持 mermaid。老版本请升级，或装 Mermaid 相关插件。

**卡在「AI 提炼中」很久**
长播客会分段提炼再整合，属于正常。超过 10 分钟没动静，看看黑色终端窗口里有没有报错。

## 进阶设置（可选，不看也能用）

项目文件夹里有个 `.env` 文件存着你的配置（网页上点保存时会自动写入）。想手动微调，可以参考 `.env.example`，几个可能用得上的：

| 配置项 | 作用 |
| --- | --- |
| `EXTRA_SCAN_DIRS` | 表达查重时，除了笔记目录，还想顺带扫哪些目录。填相对库根目录的路径，多个用逗号分隔 |
| `MAX_CHARS_SINGLE_PASS` | 超过这个字数就分段提炼再整合，默认 20000 |
| `REQUEST_TIMEOUT` | 单次请求超时秒数，默认 300 |

**想自定义笔记的写法**（改章节、改提炼口味、加自己的规则），改 `xyz2ob/prompts.py` 里的提示词即可，保存后重启生效。

**本地转录兜底**（拿不到官方文字稿时用，仅 Apple Silicon Mac）：终端里 `cd` 到项目文件夹，执行 `uv sync --extra asr`，再 `brew install ffmpeg`。装好后没有官方文稿的单集会自动走本地转录，慢很多但能用，且全程离线。

## 隐私与安全

- 所有处理都在你自己电脑上完成，只有「提炼」这一步会把文字稿发给你选的那家大模型。想彻底离线就用 Ollama。
- API Key 存在项目文件夹的 `.env` 里，小宇宙登录态存在 `~/.xyz2ob/`，两者都已被 `.gitignore` 排除，不会随代码分享出去。
- 笔记直接写进你的 Obsidian 库，不经过任何第三方服务。
