# 小宇宙播客 → Obsidian 自动笔记（xyz2ob）

> 一份写给**完全不懂技术的 Mac 用户**的保姆级说明书。你不需要会编程，也不需要看懂任何代码，只要能复制粘贴、会按回车，就能把它跑起来。

---

## 一、这个工具是什么，你能得到什么

你在小宇宙 App 里听完一期播客，觉得内容很好但记不住。以前你要么手动记笔记，要么就忘了。

这个小工具做的事是：**你粘一个小宇宙单集的分享链接进去 → 它自动去拿这一集的文字稿 → 交给大模型（AI）做结构化提炼 → 生成一篇排版整齐的 Markdown 笔记，直接写进你自己的 Obsidian 知识库里，并自动更新一个索引页。**

它有两种用法：

- **网页界面**（推荐给不熟悉命令行的人）：在你自己电脑上打开一个本地网页，粘链接、点按钮就行。这个网页只在你的电脑上运行（只监听 `127.0.0.1`，也就是「本机」），别人访问不到。
- **命令行**：在「终端」里敲 `pod <链接>`。适合已经习惯敲命令的人。

> 名词解释（第一次出现）：**Obsidian** 是一款免费的本地笔记软件；它管理笔记的那个文件夹叫 **vault（知识库）**，本质就是你硬盘上一个装满 `.md` 文件的普通文件夹。**Markdown（.md）** 是一种用纯文本写带格式文章的写法。

### 1.1 生成出来的笔记长什么样

笔记文件会命名成 `001 中文核心主旨.md` 这种形式：**三位数递增序号 + AI 起的中文标题**（标题过长会截断到 40 个字符，冒号、斜杠等文件名不允许的字符会被清掉）。

每篇笔记的结构（这是代码里实际写死的顺序）：

| 部分 | 内容 |
| --- | --- |
| YAML frontmatter（文件开头 `---` 之间的元信息区） | `title`、`source`（单集链接）、`podcast`（播客名）、`episode_title`（原始单集标题）、`host`（主播，有才写）、`published`（发布日期）、`duration`（时长）、`created`（生成日期）、`tags`（一定含 `podcast`）、`status: 待读`、`transcript_source`（文字稿来源）、`eid`（单集唯一 ID） |
| `# 标题` + 「一句话」摘要块 | Obsidian 的 `> [!abstract]` 提示框，一句话说清这期讲了什么 |
| `## 核心结论` | 编号列表，每条一个结论 + 补充说明 |
| `## 思维导图` | 一段 `mermaid` mindmap 代码块，Obsidian 里会渲染成导图 |
| `## 思维框架` | 嘉宾「是怎么想的」：思考模式 + 怎么用 + **可迁移到**哪些场景（本节只有 AI 提炼到内容时才出现） |
| `## 要点展开` | 分小节展开，行首常带 `` `hh:mm:ss` `` 时间戳，方便回听 |
| `## 金句摘录` | 引用块 + 时间点（时间点是指向单集页面的链接） |
| `## 优秀表达沉淀` | 值得学的表达：中文条目记「作用 / 怎么用」，英文条目记「含义 / 用法」，并附原句 |
| 结尾备注 | 一行说明：文字稿来源（小宇宙官方文字稿 / 本地 Whisper 转录 / 手动提供的文字稿）、生成日期、序号、原单集链接 |

如果某一节 AI 没提炼出内容，那一节会写 `_未提取到_`（思维框架整节则会直接省略）。

### 1.2 它还会自动做两件事

- **自动维护索引**：笔记目录下有一个 `_Index.md`（不存在会自动创建）。每生成一篇笔记，会在对应主题分类下追加一条双链条目（分类是 AI 判定的：科技与 AI / 商业与职场 / 文化与思考 / 语言与学习 / 其他），同时在「全部笔记（按时间）」下补一行带日期的记录。
- **同一集不会重复生成**：判重靠笔记 frontmatter 里的 `eid`。同一集再跑一次会直接跳过并告诉你已有的文件名，不会浪费 API 额度、也不会多占一个序号。想强行重做，加 `--force`（网页界面上是勾选「已记过也重新生成」），这时会**覆盖原来那篇笔记并保留原序号**。
- 另外，提炼「优秀表达」之前，它会先扫一遍你库里的历史积累（笔记目录、同级的 `Youtube/` 目录、库根目录下的 `04 ENGLISH/`），已经收过的表达就不再重复收。

## 二、开始之前需要准备什么

| 需要的东西 | 说明 |
| --- | --- |
| 一台 Mac | **Apple Silicon（M1/M2/M3/M4 芯片）**：全部功能可用，包括可选的本地语音转录。**Intel 芯片的 Mac**：主流程（官方文字稿 + AI 提炼 + 写入 Obsidian）完全可用，但**本地转录兜底不能用**（它依赖 Apple 芯片专属的 mlx-whisper）。查看自己的芯片：左上角  → 「关于本机」。 |
| 一个 Obsidian 知识库 | 没有就先去 [obsidian.md](https://obsidian.md) 下载安装，新建一个 vault 即可。 |
| 一个大模型 API Key | **API Key** 就是一串很长的密码，代表「你有权调用某个 AI 服务，费用记在你账上」。第 3 步会教你怎么申请。这一项**必需**，没有它无法生成笔记。 |
| 一个小宇宙账号（可选，但强烈建议） | 登录后可以拿小宇宙的官方文字稿：秒出、分句准、带时间戳。不登录也能用，但只能靠本地转录兜底。 |

**你不需要懂编程**，不需要会 Python，也不需要自己安装 Python。下面每一步都会告诉你「你要做什么」，然后给你一条可以直接复制粘贴的命令。

## 三、第 0 步：认识「终端」

**你要做什么：把「终端」打开，并学会往里面粘命令。**

「**终端**」（Terminal）是 macOS 自带的一个 App，它给你一个可以用打字来指挥电脑的窗口。它不会咬人，输错了最多是报个错，不会弄坏你的电脑。

打开方式（任选一种）：

- 按 `Command`+`空格`，输入 `Terminal`（或「终端」），回车。
- 打开「访达」（Finder）→ 前往 → 应用程序 → 实用工具 → 终端。

打开后你会看到类似这样的一行，最后那个 `%` 或 `$` 叫**提示符**，意思是「我在等你输入」：

```text
你的名字@MacBook-Air ~ %
```

怎么执行一条命令：把本文里代码块里的内容复制（`Command`+`C`）→ 点一下终端窗口 → `Command`+`V` 粘贴 → 按 `回车`。

怎么判断成功：**命令跑完，没有出现明显的报错文字，重新出现提示符（`%`）在等你输入，就算成功。** 很多命令成功时是安静的，什么都不打印，这是正常的，不是没执行。

如果看到红色或者一大段英文报错：**先别慌**，绝大多数情况是路径写错、少装一个东西。往下翻到 [第十六、常见问题排查](#十六常见问题排查) 对着现象找就行。

另外两个你一定会用到的小技巧：

- 终端里**没有右键粘贴**的习惯用法，请用 `Command`+`V`。
- 输入路径时，可以把 Finder 里的文件夹**直接拖进终端窗口**，路径会自动补全，不用手打。

## 四、第 1 步：安装 uv

**你要做什么：装一个叫 uv 的小工具，它会替你处理所有 Python 相关的麻烦事。**

这个项目是 Python 写的，但你不用自己装 Python：`uv` 会自动下载合适的 Python 版本（项目要求 3.10 或更新）并把依赖装在项目自己的文件夹里，不污染你的系统。

复制这一条命令到终端执行：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

这条命令干了什么：从 uv 官网下载官方安装脚本并运行，把 `uv` 装到 `~/.local/bin` 目录。成功时你会看到一堆下载和安装进度，最后有类似 `installing to /Users/你的用户名/.local/bin` 的字样。

装完之后，**关掉终端窗口再重新打开一个**（这样新装的命令才会被找到）。如果你不想重开窗口，就执行这一条临时生效的命令：

```bash
export PATH="$HOME/.local/bin:$PATH"
```

这条命令干了什么：告诉当前这个终端窗口「找命令时也去 `~/.local/bin` 里看看」。注意它**只对当前窗口有效**。

验证一下装好了：

```bash
uv --version
```

成功时会打印出一个版本号，例如 `uv 0.5.x`。如果提示 `command not found: uv`，看 [常见问题第 1 条](#1-uv-command-not-found)。

## 五、第 2 步：把项目代码下载到电脑上

**你要做什么：把这个项目的文件夹弄到你的电脑上，并让终端「进入」这个文件夹。**

### 路线 A：会用 git 的人

```bash
git clone https://github.com/<你的用户名>/xiaoyuzhou-obsidian.git ~/Documents/xiaoyuzhou-obsidian
```

把 `https://github.com/<你的用户名>/xiaoyuzhou-obsidian.git` 换成**这个仓库的实际地址**（在 GitHub 仓库页面点绿色 `Code` 按钮就能复制到）。成功时会看到 `Cloning into ...`、下载进度，最后回到提示符。

然后进入这个目录：

```bash
cd ~/Documents/xiaoyuzhou-obsidian
```

`cd` 是 change directory（切换目录）的缩写，`~` 代表你的个人主文件夹。成功时提示符前面显示的目录名会变成 `xiaoyuzhou-obsidian`。

### 路线 B：完全不会 git 的人（推荐）

1. 用浏览器打开这个项目的 GitHub 页面。
2. 点绿色的 **Code** 按钮 → 选 **Download ZIP**。
3. 下载完成后在「下载」里双击那个 zip 解压，会得到一个文件夹（可能叫 `xiaoyuzhou-obsidian-main`）。
4. 把这个文件夹拖到「**文档**」（Documents）里。建议顺手把名字改成 `xiaoyuzhou-obsidian`，好打。
5. 现在让终端进入它。先在终端里输入 `cd` 和**一个空格**（别回车）：

```bash
cd 
```

6. 然后把刚才那个文件夹**从 Finder 直接拖到终端窗口里**，路径会自动补全（含空格也会自动处理），最后按 `回车`。

验证你确实进对了目录：

```bash
ls
```

`ls` 是列出当前目录的内容。成功时你应该能看到这些名字：`pyproject.toml`、`README.md`、`.env.example`（隐藏文件不显示也没关系）、`xyz2ob`、`启动播客笔记.command`。**如果看不到 `pyproject.toml`，说明你还没进到正确的目录**，很可能是解压后多套了一层文件夹，再 `cd` 进里面那层。

> 后面所有命令都必须在这个项目目录里执行。**每开一个新终端窗口，都要先 `cd` 回这个目录。** 小技巧：按键盘 `↑` 可以调出你上次敲过的命令。

## 六、第 3 步：拿一个大模型 API Key

**你要做什么：注册一个 AI 服务商账号，充一点钱，创建一个 API Key，并记下三样东西：Key、接口地址、模型名。**

这个工具支持任何「OpenAI 兼容接口」的服务。下面给两个国内最省事的选择，二选一即可。

5. 配置时这样填：

4. 左侧「在线推理」→ 创建推理接入点，选一个长上下文的豆包模型。创建后会得到一个接入点 ID，形如 `ep-2024xxxxxx`。

其他也能用的：OpenAI（`https://api.openai.com/v1` + `gpt-4o`）。

**成本预期**：一期一小时左右的中文播客，文字稿大约一两万字，做一次提炼通常在**几分钱到几毛钱**这个量级。具体多少完全取决于你选的模型定价和播客长度——便宜的国产模型明显更省，旗舰模型会贵一些。第一次用完可以去控制台的账单页看一眼实际花了多少，心里就有数了。（超过 `MAX_CHARS_SINGLE_PASS`，默认 2 万字，会自动分段提炼再整合，调用次数会相应增加。）

**想完全离线、一分钱不花？** 可以在本机装 [Ollama](https://ollama.com) 跑开源模型，把 `LLM_BASE_URL` 填 `http://localhost:11434/v1`、`LLM_MODEL` 填你拉下来的模型（如 `qwen2.5:14b`），`LLM_API_KEY` 随便填一个非空字符串（代码要求它不为空）。代价是提炼质量通常不如云端大模型，速度也取决于你的机器。

## 七、第 4 步：找到你的 Obsidian 库路径

**你要做什么：拿到你的 Obsidian vault 在硬盘上的完整路径（绝对路径），准备待会儿填进配置。**

「绝对路径」就是从最顶层一路写下来的地址，一定以 `/` 开头，例如 `/Users/你的用户名/Documents/我的知识库`。

怎么找：

1. 打开 Obsidian，左下角设置（齿轮）→「关于」里可以看到当前库；或者点左下角的库名 →「管理库」，能看到每个库的位置。更直接的办法：在 Obsidian 里右键任意一篇笔记 →「在系统资源管理器中显示」（Reveal in Finder），Finder 就会打开这个库所在的文件夹。
2. 在 Finder 里选中你的 vault 文件夹，**按住 `Option` 键再右键**，菜单里会出现「**拷贝“xxx”的路径名称**」，点它，完整路径就复制到剪贴板了。

如果你的库放在 iCloud 里（Obsidian 默认的 iCloud 同步位置），路径通常长这样：

```text
/Users/你的用户名/Library/Mobile Documents/iCloud~md~obsidian/Documents/我的知识库
```

**路径里有空格不用加引号、也不用转义**，因为它是写进 `.env` 配置文件里的（配置文件里整行等号后面的内容都算值）。

### `NOTES_SUBDIR` 是什么

它是「笔记放在库里的哪个子文件夹」，写的是**相对 vault 的相对路径**，默认值是 `03 KNOWLEDGE/Podcasts`。也就是说笔记最终会写到 `<VAULT_PATH>/03 KNOWLEDGE/Podcasts/` 里。

- 你可以改成任何你喜欢的目录，比如 `播客笔记`。
- **这个子文件夹不存在没关系**：第一次生成笔记时会自动创建（包括中间层级）。`pod doctor` 体检时如果它还不存在，会提示 `[!] 笔记目录还不存在，首次运行会自动创建`，这不是错误。
- 但 **`VAULT_PATH` 本身必须真实存在**，否则会直接报错停下。

## 八、第 5 步：创建配置文件 `.env`

**你要做什么：复制一份配置模板，填上你的 Key 和库路径。**

`.env` 是一个纯文本文件，每行一条 `名字=值`，用来存那些不该写进代码里的设置（这类设置常被叫做**环境变量**）。

第一条命令（在项目目录里执行）：

```bash
cp .env.example .env
```

这条命令干了什么：把仓库里自带的模板 `.env.example` 复制成一份你自己的 `.env`。成功时终端什么都不打印，直接回到提示符。

第二条命令，打开它来编辑：

```bash
open -e .env
```

这条命令干了什么：用 macOS 自带的「文本编辑」App 打开 `.env`。成功时会弹出一个窗口，里面就是配置内容。（改完记得 `Command`+`S` 保存。）

逐项说明：

| 配置项 | 必填？ | 填什么 |
| --- | --- | --- |
| `VAULT_PATH` | **必填** | 第 4 步复制的 vault 绝对路径。整行只保留路径本身，不要加引号（加了也会被自动去掉），不要留多余文字。 |
| `NOTES_SUBDIR` | 可留默认 | 笔记子目录，默认 `03 KNOWLEDGE/Podcasts`。留空则用默认值。 |
| `LLM_API_KEY` | **必填** | 第 3 步拿到的 Key。**没有它无法生成笔记。** |
| `LLM_BASE_URL` | 建议按服务商填 | 接口地址，要填到 `/v1` 或 `/api/v3` 这一层。留空则用默认的火山方舟地址。 |
| `LLM_MODEL` | 建议按服务商填 | 模型名或推理接入点 ID。留空则用默认的 `doubao-seed-1-6-250615`。 |
| `ASR_MODEL` | 可留默认 | 本地转录用的 Whisper 模型，默认 `mlx-community/whisper-large-v3-turbo`。只有走本地转录时才用到。 |
| `MAX_CHARS_SINGLE_PASS` | 可留默认 | 超过这个字数就分段提炼再整合，默认 `20000`。 |
| `REQUEST_TIMEOUT` | 可留默认 | 单次请求超时秒数，默认 `300`。模型慢、经常超时可以调大。 |

小提示：也可以先跳过手动编辑，直接进入第 7 步用**网页界面的「设置」区**来填 Key、接口地址、模型名、库路径和子目录，点「保存设置」会自动写回 `.env`（会保留你文件里的注释）。

> ⚠️ **`.env` 是你的私密文件。** 里面有能花你钱的 API Key。仓库的 `.gitignore` 已经把 `.env` 排除在版本管理之外，所以它不会被上传到 GitHub。但请你自己也务必注意：**不要把 `.env` 发给别人、不要截图带上 Key、不要贴到聊天群或 issue 里。** 万一泄露了，去服务商控制台把那个 Key 删掉重建一个。

## 九、第 6 步：体检 `pod doctor`

**你要做什么：让工具自己检查一遍配置对不对。**

```bash
uv run pod doctor
```

这条命令干了什么：`uv run` 会在第一次执行时自动下载 Python 和依赖（`httpx`、`fastapi`、`uvicorn`），所以**首次运行会慢一些、并打印一堆安装进度，这是正常的**；然后运行体检命令 `pod doctor`。

它会依次检查这几项：

| 检查项 | 通过的样子 | 没通过怎么修 |
| --- | --- | --- |
| 配置文件能否加载 | `[✓] 配置文件已加载`，并打印 vault 路径 | `[×] 配置：…` 通常是没有 `.env` 或没填 `VAULT_PATH` → 回第 5 步 |
| vault 是否存在 | `[✓] vault 存在` | `[×] vault 不存在` → `.env` 里 `VAULT_PATH` 写错了（多空格、少一层目录、路径带引号引起的错位），回第 4 步重新复制路径 |
| 笔记目录 | `[✓] 笔记目录存在，已有 N 个 md，下一个序号 0xx` | `[!] 笔记目录还不存在，首次运行会自动创建` → 无需处理，不影响使用 |
| 小宇宙登录态 | `[✓] 小宇宙已登录（昵称）→ 可用官方文字稿` | `[!] 小宇宙未登录 → 只能本地转录` → 想要官方文稿就做第 8 步登录 |
| 大模型 Key 与连通性 | `[✓] LLM Key 已配置（前 6 位…）`，然后真的试调一次，成功打印 `[✓] LLM 连通，返回：可用` | `[×] 没有配置 LLM_API_KEY` → 回第 5 步填 Key；`[×] LLM 调用失败` → 看提示里的原因（401 是 Key 错、404 是接口地址错、其他多是模型名错或余额不足），对照第 3 步的表 |
| 本地转录环境（可选） | `[✓] mlx-whisper 已安装`、`[✓] ffmpeg 已安装` | `[!]` 是提醒不是错误。只在需要本地转录兜底时才要装，见 [第十三、可选：装本地转录兜底](#十三可选装本地转录兜底) |

最后它会打印状态目录（默认 `~/.xyz2ob`）和一句结论：`体检通过，可以直接用了。` 或 `有问题需要先处理（上面标 × 的项）。`

只要**没有 `[×]`**，就可以继续。`[!]` 是提示，不阻塞使用。

> 不想每次体检都真的花一次 API 调用（虽然只要几毫钱）：加 `--skip-llm`，即 `uv run pod doctor --skip-llm`。

## 十、第 7 步：启动网页界面

**你要做什么：把本地网页界面跑起来，以后日常就用它。**

### 方式 A：双击 `启动播客笔记.command`（最省事）

在 Finder 里打开项目文件夹，双击 `启动播客笔记.command`。它会自动进入项目目录、补好 PATH，然后执行 `uv run pod ui`。

**首次双击 macOS 可能会拦截**，弹窗说无法打开/来自未知开发者。处理办法：打开「系统设置」→「隐私与安全性」→ 往下滚到「安全性」那一段，会看到刚被拦截的文件 → 点「**仍要打开**」→ 再确认一次。

如果双击后没有反应、或者提示权限不足（`Permission denied`），在终端里执行一次：

```bash
chmod +x 启动播客笔记.command
```

这条命令干了什么：给这个文件加上「可执行」权限。成功时无输出，之后再双击就正常了。

### 方式 B：终端命令

```bash
uv run pod ui
```

成功时终端会打印：

```text
  播客笔记界面已启动：http://127.0.0.1:8765
  关掉这个窗口就会停止服务。
```

大约 1 秒后浏览器会自动打开 **<http://127.0.0.1:8765>**（默认端口 `8765`）。没自动打开就手动在浏览器地址栏输入这个地址。

- 想换端口：`uv run pod ui --port 9000`
- 不想自动开浏览器：`uv run pod ui --no-browser`
- **这个终端窗口必须保持开着**，服务才在运行；关掉窗口（或按 `Control`+`C`）就停止。

### 界面上有什么

从上往下：

1. **顶部状态胶囊**（4 个小圆点标签）：`Vault 已连接` / `Vault 路径无效`；`小宇宙已登录 昵称` / `小宇宙未登录`；`模型 xxx` / `未配置大模型 Key`；`已有 N 篇 · 下一篇 0xx`。
2. **生成区**（最主要）：
   - 一个输入框：`粘贴小宇宙单集链接或整段分享文案`
   - 「**读剪贴板**」按钮：把你刚复制的内容自动填进输入框
   - 「**生成笔记**」按钮：开始跑，运行中会变成「处理中…」并暂时不可点
   - 「**文字稿来源**」下拉框：`自动（优先官方文稿）` / `只用官方文稿` / `强制本地转录`
   - 「**已记过也重新生成**」勾选框：等于命令行的 `--force`
3. **处理进度**：一个黑底日志区，实时逐行显示进度（识别到的单集 ID、单集标题、文字稿获取情况、AI 提炼进度、写入结果等），出错的行会标红。
4. **结果区**（跑完才出现）：标题显示「笔记已生成」或「这一集之前已经记过了」；下面一行是笔记文件名 + 《播客名》单集标题 · 时长 · 发布日期 · 索引分类；有「**在 Obsidian 打开**」按钮；还有一个「**查看笔记全文**」折叠块可以直接读全文。
5. **小宇宙登录**：手机号输入框 + 「发送验证码」，验证码输入框 + 「登录」，右上角还有「退出登录」。
6. **设置**：大模型 API Key（留空表示不修改）、接口地址、模型名、Vault 路径、笔记子目录，加一个「保存设置」按钮（写回 `.env`）和一个「**测试大模型连通**」按钮。界面自己也提示：改完设置**重启一下服务**才会完全生效（关掉窗口再重新启动）。

## 十一、第 8 步：登录小宇宙（拿官方文字稿）

**你要做什么：用手机号做一次短信登录，之后就能直接用官方文字稿。**

为什么要登录：小宇宙 App 里那份「文稿」是官方 AI 转录的，**分句准、带时间戳、几秒就能拿到、不耗你的电脑算力**，但获取它的接口需要登录态。不登录也能用这个工具，只是只能走**本地转录兜底**（要装额外东西、慢很多，且 Intel Mac 不支持）。

> 名词解释：**token**（令牌）是登录成功后服务器发给你的一串凭证，相当于「已登录」的门禁卡，有了它就不用每次都输验证码。

网页界面里：在「小宇宙登录」区填手机号（**不含 +86**）→ 点「发送验证码」（成功会提示「验证码已发送，注意查收短信」）→ 把收到的验证码填进第二个框 → 点「登录」。成功会显示「登录成功：你的昵称」，顶部状态胶囊也会变成已登录。

命令行等价写法：

```bash
uv run pod login
```

它会先问你「小宇宙账号手机号（不含 +86）：」，回车后发送验证码，再问「收到的验证码：」。成功会打印 `✓ 登录成功：<昵称>`，并告诉你 token 存放位置。

**token 存在哪**：`~/.xyz2ob/xiaoyuzhou_token.json`（`~` 是你的主文件夹）。文件权限被设为 `600`（只有你本人能读写），**只保存在本机、不会上传**，也在 `.gitignore` 里被排除。

退出登录（删除本地 token）：

```bash
uv run pod logout
```

成功打印 `✓ 已删除本地登录 token。`；本来就没登录会打印 `本来就没有登录 token。` 网页界面上点「退出登录」是一样的效果。

登录会过期。过期时你会看到 `登录已过期。→ 重新执行 pod login`，照做即可（工具会先自动尝试用 refresh token 续期，续不上才让你重登）。

## 十二、第 9 步：生成你的第一篇笔记

**你要做什么：从小宇宙 App 复制一个单集链接，粘进界面，等它跑完，去 Obsidian 看结果。**

1. 打开小宇宙 App，找到想记的那一集 → 点分享 → 「复制链接」（复制**整段分享文案**也行，工具会自己从里面挑出链接）。支持的输入：完整单集链接、带 `?s=` 参数的分享链接、整段分享文案、`xyzfm.link` 短链、24 位的裸 eid。
2. 回到浏览器里的界面，点「**读剪贴板**」（或直接 `Command`+`V` 粘到输入框）。
3. 文字稿来源保持默认「自动（优先官方文稿）」。
4. 点「**生成笔记**」。

**大概要等多久**：如果有官方文字稿，整体通常 **1～3 分钟**，绝大部分时间花在 AI 提炼上（一小时的播客、又长又超过分段阈值的话会更久）。走本地转录会明显更慢（先下载音频再转录）。

**进度日志会显示什么**（真实的日志文案）：

```text
识别到单集 ID：xxxxxxxxxxxxxxxxxxxxxxxx
《某播客》某单集标题（01:02:03）
正在获取小宇宙官方文字稿…
拿到官方文字稿，共 1234 段。
AI 提炼中，长播客会分段处理，请稍等…
已积累 87 条表达，本次会避开重复。
已写入：012 某个中文标题.md
索引分类：科技与 AI
完成
```

期间可能出现的其它提示：`这一集还没有官方文稿。`、`未登录小宇宙，跳过官方文字稿…`、`正在下载音频…` / `音频下载 30%` / `正在本地转录…`、`注意：这是付费单集…`、`这一集已经记过了：xxx.md`。

**跑完去哪看**：结果区会显示文件名，点「在 Obsidian 打开」就直接跳进 Obsidian。或者自己在 Obsidian 侧栏进入 `03 KNOWLEDGE/Podcasts`（或你设的子目录），新笔记就在里面。iCloud 库偶尔要等几秒同步。

**`_Index.md` 会怎么变**：同目录下的 `_Index.md`（没有会用模板新建）会多两处内容——在 AI 判定的主题分类小节下多一行 `- [[012 某个中文标题]] — 一句话摘要`，在「全部笔记（按时间）」下多一行 `- [[012 某个中文标题]] - 2026-08-16`。分类小节里原来的 `_(暂无)_` 占位会自动消失。

### 命令行等价写法

```bash
uv run pod "<你的小宇宙链接>"
```

链接两边**建议加英文双引号**，因为分享链接里常带 `?` 和 `&` 这类终端会误解的符号。成功时终端最后会打印 `✓ 已写入：/完整/路径/012 xxx.md`。

不带链接直接跑，会自动读你的剪贴板：

```bash
uv run pod
```

生成后顺手用 Obsidian 打开：

```bash
uv run pod --open "<你的小宇宙链接>"
```

## 十三、可选：装本地转录兜底

**你要做什么：只有当你遇到「这一集没有官方文稿」时，才需要做这一步。**

适用范围与限制：

- **只在 Apple Silicon（M 系列芯片）上可用**，Intel Mac 不适用（`mlx-whisper` 是 Apple 芯片专属）。
- 只有拿不到官方文字稿的单集才会用到它（或者你主动选「强制本地转录」）。
- **首次运行会先下载语音模型**（默认 `mlx-whisper/whisper-large-v3-turbo`，体量数百 MB），需要耐心等；之后就不用再下。
- **比官方文稿慢很多**：要先把整集音频下载下来，再在本机转录，一小时音频通常要几分钟；期间风扇可能会转。

两条命令，在项目目录里依次执行：

```bash
uv pip install mlx-whisper
```

这条命令干了什么：把本地转录用的 `mlx-whisper` 装进这个项目的环境里。成功时最后会打印安装了哪些包。

```bash
brew install ffmpeg
```

这条命令干了什么：装 `ffmpeg`（一个处理音视频的通用工具，转录前要用它读音频）。它需要你先装过 [Homebrew](https://brew.sh)（macOS 上最常用的软件包管理器；没装就照它官网首页那条命令装一下）。成功时会看到一长串下载和安装过程。

装完再体检确认：

```bash
uv run pod doctor
```

看到 `[✓] mlx-whisper 已安装` 和 `[✓] ffmpeg 已安装` 就好了。

## 十四、常用命令速查表

以下命令都在项目目录里执行。若你没有把 `pod` 设为全局命令，就都写成 `uv run pod ...`。

| 命令 | 作用 |
| --- | --- |
| `uv run pod "<链接>"` | 完整流程：抓文字稿 → AI 提炼 → 写入 Obsidian（`run` 子命令可省略） |
| `uv run pod` | 同上，但链接从剪贴板读 |
| `uv run pod ui` | 启动本地网页界面（默认 `http://127.0.0.1:8765`，自动开浏览器） |
| `uv run pod doctor` | 体检：配置 / vault / 笔记目录 / 小宇宙登录态 / 大模型连通 / 转录环境 |
| `uv run pod login` | 小宇宙短信登录，拿官方文字稿权限 |
| `uv run pod logout` | 删除本地登录 token（退出登录） |
| `uv run pod transcript "<链接>"` | 只导出文字稿到屏幕，不调用 AI、不写笔记 |

各子命令的参数：

| 参数 | 属于 | 作用 |
| --- | --- | --- |
| `--prefer auto\|official\|asr` | `run` / `transcript` | 文字稿来源偏好，默认 `auto`（先官方、拿不到再本地转录） |
| `--official` | `run` | 等于 `--prefer official`：只用官方文字稿，拿不到就报错 |
| `--asr` | `run` | 等于 `--prefer asr`：强制本地转录 |
| `--transcript-file <文件>` | `run` | 直接用一个本地文字稿文本文件，跳过所有抓取（每行算一段） |
| `--save-transcript <文件>` | `run` | 顺手把这次用到的文字稿另存到指定路径 |
| `--no-write` | `run` | 只把笔记打印到屏幕，不写进 vault（想先看看效果） |
| `--force` | `run` | 这一集已经记过也重新生成：覆盖原笔记、保留原序号、并刷新索引条目 |
| `--open` | `run` | 生成后自动用 Obsidian 打开这篇笔记 |
| `--plain` | `transcript` | 导出的文字稿不带时间戳 |
| `--port <数字>` | `ui` | 换端口，默认 `8765` |
| `--host <地址>` | `ui` | 监听地址，默认 `127.0.0.1`（仅本机） |
| `--no-browser` | `ui` | 启动后不自动打开浏览器 |
| `--skip-llm` | `doctor` | 体检时不真的试调大模型 |
| `--phone` / `--code` | `login` | 直接把手机号 / 验证码作为参数给出，不交互输入 |
| `--vault <路径>` | 所有子命令 | 临时覆盖 vault 路径（不改 `.env`） |
| `--model <模型名>` | 所有子命令 | 临时换一个模型（不改 `.env`） |

想把文字稿存成文件，也可以用终端的重定向：

```bash
uv run pod transcript "<链接>" > 文字稿.txt
```

（想让 `pod` 变成随处可用的短命令：在终端执行一次 `echo 'alias pod="uv run --project ~/Documents/xiaoyuzhou-obsidian pod"' >> ~/.zshrc`，再执行 `source ~/.zshrc`，把路径换成你自己的项目路径。之后直接敲 `pod ...` 即可。）

## 十六、常见问题排查

遇到问题的通用第一步：**先跑 `uv run pod doctor`**，它会直接指出大部分问题。

### 1. `uv: command not found`

**现象**：敲 `uv --version` 或 `uv run pod ...`，终端回 `command not found: uv`。
**为什么**：uv 装在 `~/.local/bin`，但当前终端窗口还不知道去那里找命令（常见于刚装完没重开窗口）。
**怎么修**：先关掉终端重新开一个再试。还不行就执行 `export PATH="$HOME/.local/bin:$PATH"` 后再试（只对当前窗口有效）；如果连 `~/.local/bin/uv` 都不存在，说明第 1 步的安装其实没成功，重跑一次安装命令。

### 2. `没有配置 Obsidian vault 路径` / `.env` 好像没生效

**现象**：明明填了配置，运行还是说没配置，或用的还是旧值。
**为什么**：三种常见原因：① `.env` 没放在**项目根目录**（必须和 `pyproject.toml` 同一层）；② 文件名不对（写成了 `env`、`.env.txt`——「文本编辑」有时会自动加 `.txt`）；③ 网页界面在你改 `.env` 之前就启动了。
**怎么修**：确认在项目目录里执行 `ls -a` 能看到 `.env`；用 `open -e .env` 确认内容；网页界面改配置后关掉窗口重新启动。另外注意：**系统环境变量优先级高于 `.env`**，如果你以前在 `~/.zshrc` 里设过同名变量，它会盖掉 `.env`。

### 3. `Obsidian vault 路径不存在` / `[×] vault 不存在`

**现象**：体检时 vault 那行是 `[×]`。
**为什么**：路径写错了。最常见是手打漏字、库名里的空格或特殊字符抄错、iCloud 路径少了 `Library/Mobile Documents/...` 那几层。
**怎么修**：回第 4 步，用「按住 Option → 拷贝路径名称」重新复制，整行替换 `VAULT_PATH=` 后面的内容。不要加引号，不要在等号两边留多余空格。

### 4. `大模型接口鉴权失败（401）` 或余额不足类报错

**现象**：`[×] LLM 调用失败：大模型接口鉴权失败（401）`，或 `大模型返回 HTTP 4xx`，提示里带余额/配额字样。
**为什么**：Key 复制不全（少了几位或带了空格/换行）、Key 已被删除、账号没充值或没开通该模型。
**怎么修**：去服务商控制台重新生成一个 Key，整行替换 `LLM_API_KEY=` 后面的值（注意不要留行尾空格）；顺便看一眼余额。改完 `uv run pod doctor` 再验。

### 5. `接口地址不对（404）`

**现象**：报错写着 `接口地址不对（404）：https://.../chat/completions`。
**为什么**：`LLM_BASE_URL` 层级填错了，比如只填了 `https://api.deepseek.com`，或多写了 `/chat/completions`。
**怎么修**：填到 `/v1`（或火山方舟的 `/api/v3`）这一层就好，参考第 3 步的表。

### 6. 模型名写错

**现象**：`大模型返回 HTTP 400/404`，报文里有 `model not found`、`invalid model` 之类；或者 `模型输出不是合法 JSON`。
**为什么**：`LLM_MODEL` 写错了：火山方舟要填推理接入点 ID（`ep-...`）或正确的模型名；DeepSeek 是 `deepseek-chat`。另外能力太弱的小模型可能吐不出规范 JSON。
**怎么修**：按服务商文档核对模型名；重试一次；反复失败就换一个指令跟随能力更强的模型（`--model xxx` 可以临时试）。

### 7. `登录已过期` / `还没登录小宇宙`

**现象**：日志里出现 `登录已过期。→ 重新执行 pod login`，或界面提示未登录。
**为什么**：token 有有效期，续期也可能失败；或者你之前执行过 `pod logout`。
**怎么修**：重新登录一次（`uv run pod login`，或界面上的「小宇宙登录」区）。

### 8. `这一集还没有官方文稿。`

**现象**：日志显示这一集没有官方文稿，然后要么转向本地转录，要么报错说本地转录环境没装好。
**为什么**：小宇宙不是每一集都生成了文稿（新发布的、小众节目常见）。
**怎么修**：三个选择：① 装本地转录兜底（[第十三节](#十三可选装本地转录兜底)）；② 自己找一份文字稿存成 txt，用 `--transcript-file 文件名` 喂给它；③ 换一集。如果你用了 `--official` / 「只用官方文稿」，它会直接报错，这是预期行为。

### 9. 付费单集

**现象**：日志出现 `注意：这是付费单集（payType=...），可能拿不到内容。`，之后可能报 `这一集没有可下载的音频地址。` 或 `下载到的音频文件异常小，可能是付费/加密内容。`
**为什么**：付费内容的文字稿和音频受保护，工具拿不到。
**怎么修**：没有绕过的办法。请尊重版权，换免费单集，或自己整理好文字稿用 `--transcript-file` 喂进来。

### 10. 思维导图（mermaid）在 Obsidian 里渲染不出来

**现象**：`## 思维导图` 那一段显示成一块代码，或者显示红色报错。
**为什么**：① 你的 Obsidian 版本较旧，对 mermaid 的 `mindmap` 图表类型支持不全（mindmap 是较新的语法）；② 处于「源码模式」，本来就不渲染；③ 极少数节点文字里有特殊字符导致解析失败。
**怎么修**：把 Obsidian 升级到最新版；切换到「阅读视图 / 实时预览」；仍不行就直接手动改一下那几行节点文字（它只是普通文本），或删掉这段代码块——不影响笔记其他部分。

### 11. 笔记没出现在 Obsidian 里

**现象**：终端说 `✓ 已写入：...`，但 Obsidian 里翻不到。
**为什么**：① `NOTES_SUBDIR` 写的不是你以为的那个目录，笔记被写进了一个新建的文件夹里；② vault 路径指到了另一个库；③ iCloud 还在同步。
**怎么修**：看终端/界面打印的**完整路径**，照着这个路径在 Finder 里找一下，就知道它到底写哪去了。然后把 `.env` 的 `NOTES_SUBDIR` 改成你想要的目录（用 `/` 分隔层级，不要以 `/` 开头）。等几秒让 iCloud 同步，或在 Obsidian 里切换一下库刷新。

### 12. 同一集重复运行被跳过了

**现象**：日志 `这一集已经记过了：012 xxx.md`、`想重新生成加 --force`，结果区标题写「这一集之前已经记过了」。
**为什么**：这是**故意的**防重复设计，按笔记 frontmatter 里的 `eid` 判重，省钱也避免占用新序号。
**怎么修**：确实想重做就加 `--force`（界面上勾「已记过也重新生成」）。注意它会**覆盖**原来那篇笔记，序号不变；索引里的分类条目会刷新，「全部笔记」里的原始日期保持不动。想保留旧版本请先手动备份。

### 13. 双击 `启动播客笔记.command` 被系统拦截 / 没反应

**现象**：弹窗说无法打开，或者双击后终端闪一下就没了。
**为什么**：macOS 的 Gatekeeper 会拦截来自网络下载的脚本；或者文件缺少可执行权限；或者 uv 不在 PATH 里。
**怎么修**：「系统设置 → 隐私与安全性 → 安全性」里点「**仍要打开**」；执行一次 `chmod +x 启动播客笔记.command`；如果窗口里闪现的是 `uv: command not found`，先解决第 1 条。任何时候都可以退回到 `uv run pod ui` 这条命令。

### 14. 端口被占用

**现象**：启动界面时报错，信息里有 `Address already in use` 或 `port 8765`。
**为什么**：你之前已经启动过一个界面还没关（另一个终端窗口里跑着），或者别的软件占了 `8765`。
**怎么修**：先找找是不是还有一个开着的终端窗口，有就切过去用；或者换端口：`uv run pod ui --port 8788`，然后浏览器访问 `http://127.0.0.1:8788`。

### 15. `没找到 __NEXT_DATA__` / `解析单集数据失败` / `单集不存在或已下架`

**现象**：刚开始就失败，提示解析页面失败或单集不存在。
**为什么**：链接不对（复制到了播客主页而不是单集页）、单集已下架、或者小宇宙网页改版导致解析逻辑失效。
**怎么修**：先确认链接形如 `https://www.xiaoyuzhoufm.com/episode/<24位ID>`；换一集验证一下。如果所有单集都失败，很可能是小宇宙改版了，需要更新 `xyz2ob/scrape.py`（欢迎提 issue）。

### 16. 卡在「AI 提炼中」很久 / 超时

**现象**：日志停在 `AI 提炼中…` 好几分钟，或最后报网络超时。
**为什么**：长播客会分段多次调用模型，本来就慢；也可能是模型服务端慢或网络不稳。
**怎么修**：耐心等（一小时的播客几分钟是正常的）；把 `.env` 里的 `REQUEST_TIMEOUT` 调大（如 `600`）；或把 `MAX_CHARS_SINGLE_PASS` 调小让每次请求更短。

## 十七、隐私与安全

- **所有处理都在你自己的电脑上进行**：抓取、（可选的）本地转录、渲染 Markdown、写入 Obsidian，全在本机完成。网页界面只监听 `127.0.0.1`，同一个局域网里的其他设备也访问不到。
- **唯一离开本机的数据**是：为了做提炼，文字稿会发给**你自己在 `.env` 里配置的那个大模型接口**。如果你介意，把 `LLM_BASE_URL` 指向本机的 Ollama，就是彻底离线的全本地流程。
- **生成的笔记只写进你自己的 Obsidian 库**，不上传任何地方。
- **API Key 只存在你本机的 `.env` 里**；小宇宙登录 token 只存在 `~/.xyz2ob/xiaoyuzhou_token.json`，权限 `600`（仅你本人可读写）。两者都被 `.gitignore` 排除，不会被 git 记录、也不会推到 GitHub。
- **仓库里为什么只有 `.env.example`**：因为 `.env.example` 是一份**不含任何秘密的空白模板**，只给出字段名和示例格式，方便别人照着填。真正带 Key 和你私人路径的 `.env` 是你本地生成、永远不入库的。这样任何人 clone 这个仓库都不会拿到别人的凭证。
